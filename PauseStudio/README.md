# Pause Studio v1.4

A macOS menu-bar app for guided breathing, stretching, and hydration breaks.

## Install

1. Download the repository ZIP from the website or GitHub repository.
2. Extract it, then open the `PauseStudio` folder.
3. Open Terminal in this folder and run `bash Install.command`.
4. Look for the Pause Studio icon in the menu bar.

Works with Apple Command Line Tools. The installer builds a native Mac application in `~/Applications/PauseStudio.app`.

## Features

- Working-hour and weekday schedules
- Custom reminder frequency and pause duration
- Rotating breathing, stretching, hydration activities
- Guided countdown and chime
- Next pause and today's schedule
- Enable/Disable Reminders toggle
- Snooze, Skip, Done

The installer retains local preferences in `~/Library/Application Support/PauseStudio/`.

Note: This project builds from source on your Mac; it is not a signed or notarized app binary.
