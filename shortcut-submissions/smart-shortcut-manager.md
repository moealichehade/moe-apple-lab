# Smart Shortcut Manager

Created by **Mohamad Ali Chehade (@MoeAliChehade)**.

Smart Shortcut Manager brings sharing, exporting, backing up, browsing, and importing Apple Shortcuts into one menu.

## Features

- **Share Shortcuts** — select a shortcut and use Apple's sharing controls, including iCloud links when available.
- **Export Shortcuts** — save selected shortcuts as files.
- **Copy Sharing Links** — copy a sharing link when Apple's sharing flow supplies one.
- **Backup All Shortcuts** — save a copy of the collection.
- **Backup Selected Shortcuts** — choose which shortcuts to export.
- **Browse Saved Backups** — access previously saved files.
- **Restore Shortcuts** — open saved files for review and import into Apple Shortcuts.
- **Open Shortcuts** — open Apple's Shortcuts app.

## How to use

Open Smart Shortcut Manager, select the action you need, and follow the native Apple sharing, file-selection, and import steps. Some operations require confirmation.

The intended backup folder is **iCloud Drive → Shortcuts → Smart Shortcut Manager**. iCloud Drive synchronization and the appropriate access permissions are required to use the same backups across devices.

## Why it helps

The manager collects common sharing and backup tasks in a single place and makes it easier to find previously exported shortcuts.

## Installation and review

The signed `.shortcut` file will be published under `downloads/shortcuts/smart-shortcut-manager.shortcut` when its binary upload completes. Review all requested permissions before importing. Feature descriptions are provided by the creator; availability can depend on the OS version and native sharing restrictions.
