# Smart PDF Toolbox

**Created by @MoeAliChehade — Mohamad Ali Chehade**

Smart PDF Toolbox is an all-in-one Apple Shortcut designed to make working with PDF files easier on iPhone, iPad, and Mac.

It brings useful PDF tools together in one simple menu.

## Features

- Merge multiple PDFs into one document.
- Split PDFs into individual pages.
- Extract selected pages from a PDF.
- Compress PDFs to reduce file size where possible.
- Extract text from PDF documents.
- Use Apple Intelligence to summarize, explain, and analyze PDF content.
- Create PDFs from images, text, and supported documents.
- Annotate and sign PDFs using Markup.
- Rename, share, and print PDF files.
- Copy extracted content or save it to Apple Notes.

## How It Works

Run Smart PDF Toolbox, select the action you need, choose your PDF file, and follow the on-screen instructions.

## Why I Created It

Working with PDF files on an iPhone or iPad can sometimes be frustrating. I wanted to bring everyday PDF tools into one place, reducing unnecessary steps and making document management easier.

Designed for everyday productivity across the Apple ecosystem.
