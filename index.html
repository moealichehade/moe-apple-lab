APPLE SHORTCUTS · CLIPBOARD MANAGER

Copy it. Save it. Find it. Reuse it.

Clipboard Manager is a standalone Apple Shortcut created by Mohamad Ali Chehade (Moe) · @MoeAliChehade. Save copied text and bring it back later from one simple menu. It runs through the Apple Shortcuts app on iPhone and iPad .

Install Clipboard Manager

Download Clipboard Manager.shortcut from the library. On iPhone or iPad, open the file in Shortcuts, review the actions and permissions, and confirm Add Shortcut. Run Clipboard Manager in Shortcuts to open its main menu. Allow access to files or the clipboard if prompted.

Download the original Shortcut using the button above.

1–3 · View, save, retrieve

1. Clipboard MonitorOpen your saved clipboard entries and select an available item.
2. Save ClipboardSave the text that is currently copied to your clipboard.
3. Retrieve ClipboardBrowse saved entries, select one, and copy it back to the clipboard.

4–6 · Organize your history

4. Delete Selected ItemsChoose entries you no longer need and confirm their deletion.
5. Clear HistoryRemove all saved entries after confirmation.
6. Exit Clipboard ManagerClose the Shortcut when you are done.

One menu, simple everyday workflow

After completing an action, return to the main menu or exit. Clipboard Manager uses native Apple Shortcuts menus, lists, conditions and saved data, without requiring the Mac clipboard-history app.

Privacy: Any text you save to history may contain personal information. Review saved entries regularly, avoid storing passwords, and use Delete Selected Items or Clear History when needed.

APPLE SHORTCUTS · READING PROGRESS TRACKER

Read. Reflect. Remember.

Created by Mohamad Ali Chehade (Moe) · @MoeAliChehade. Reading Progress Tracker helps you follow your reading journey, record progress and keep the ideas you want to remember. It tracks one active book at a time using native Apple Shortcuts on iPhone, iPad and Mac.

Install Reading Progress Tracker

Install the original Reading Progress Tracker.shortcut in Apple Shortcuts: open the file on iPhone, iPad or Mac, review its actions and requested permissions, and select Add Shortcut. Run it from the Shortcuts app and choose an action from its menu.

Download the original Shortcut using the button above.

Set up and track your book

1. Add or Change BookEnter the book title, author and total number of pages.
2. Update Current PageAfter a reading session, record the page you have reached.
3. View Reading ProgressCheck how far you have progressed through your current book.
4. Save Reading ReflectionWrite down an idea, thought or lesson you want to remember.

Reflect and finish

5. View ReflectionsReturn to reflections you have saved while reading.
6. Mark Book FinishedRecord that you completed your current book.
7. Clear Current BookClear the current book so you can begin another.

Example: Add a 300-page book, enter page 120 after reading, then open View Reading Progress to check your completion. Save a reflection when an idea stands out.

More than a reading counter

Reading is not only about finishing pages. It's also about understanding, reflecting and remembering what matters. Use this Shortcut to notice what each book teaches you, at your own pace.

Before clearing a book, review your recorded reflections. The Shortcut is intended for one active book at a time, not as a multi-book library.

APPLE SHORTCUT PROJECTS · SEVEN CONNECTED SHORTCUTS

One project. Seven Shortcuts. One connected workflow.

My Apple Projects Ecosystem was designed and built by Mohamad Ali Chehade (Moe) · @MoeAliChehade to connect Apple Reminders, Apple Notes and Apple Calendar without another project-management subscription.

Start here: install the seven Shortcuts

Download the Apple Projects Ecosystem package, extract it, and import each .shortcut file into Apple Shortcuts on your Mac, iPhone or iPad. Review the actions and accept requested access to Reminders, Notes and Calendar. Begin with Project Starter, then use Project Control Center and the other workflows around the same project.

Download All Seven Project Shortcuts ↓

Suggested sequence: Project Starter → Project Control Center → Capture or Meeting → Actions → Time-Block → Workspace Launcher → End-of-Day Review.

Each of the seven Project Shortcuts can also be downloaded separately from the Apple Shortcuts Library.

How each Shortcut works

1. Project Starter

Create a project and establish its task sections, Notes space and structure for every connected workflow.

Step 1Enter a project name and details
Step 2Set up Apple Reminders sections: NEXT, WAITING, LATER and PROJECT INFO
Step 3Create or connect the project's information in Apple Notes
Step 4Use the same project name and structure across the other shortcuts

2. Project Control Center

Choose an existing project and navigate its tasks, project notes, schedule and related actions.

Step 1Select a project
Step 2Review its Reminders tasks and progress
Step 3Access the matching Apple Note
Step 4Check related Calendar activities
Step 5Navigate to the project function you need

3. Universal Capture Projects

Capture ideas, tasks and information quickly, and place them under the right project.

Step 1Capture an idea, task or important information
Step 2Select the project it belongs to
Step 3Place the new item into that project's workflow
Step 4Return to it when you work on the project

4. Meeting → Actions

Turn meeting decisions into organized follow-up tasks connected with project notes.

Step 1Choose the relevant project
Step 2Record meeting details and decisions
Step 3Identify follow-up actions and responsibilities
Step 4Keep context in Notes and tasks in Reminders

5. Auto Time-Block Tasks

Select a project task and reserve focused work time in Apple Calendar.

Step 1Select a project
Step 2Choose the task you want to tackle
Step 3Pick a time for focused work
Step 4Reserve the slot in Apple Calendar while keeping the task in Reminders

6. Project Workspace Launcher

Open your project resources and jump into work without searching multiple apps.

Step 1Choose your project
Step 2Open its workspace
Step 3Access associated notes and resources
Step 4Continue working in the right place

7. End-of-Day Task Processor

Review today's work, organize unfinished tasks and prepare tomorrow's priorities.

Step 1Review today's project tasks
Step 2Identify completed and unfinished work
Step 3Organize what still needs attention
Step 4Prepare tomorrow's priorities

How the Apple ecosystem connects

Reminders — what to do: Project tasks, deadlines, progress and the NEXT, WAITING, LATER and PROJECT INFO sections.

Notes — what you need to know: Ideas, project details, meeting context and useful references.

Calendar — when to do it: Scheduled activities and protected focus sessions.

Shortcuts — how to move between them: Each Shortcut handles one part of the workflow, using the same project structure.

Example: planning a workshop

Morning: Create the workshop using Project Starter and organize its tasks.

During the day: Capture an idea under the workshop with Universal Capture Projects.

After a meeting: Use Meeting → Actions to record decisions and follow-up tasks.

Planning time: Review tasks in Project Control Center and reserve time with Auto Time-Block Tasks.

Working: Open notes and resources with Project Workspace Launcher.

End of day: Review unfinished work with End-of-Day Task Processor.
