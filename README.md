## Plan & Act

Keep project details in Apple Notes, actions in Apple Reminders, and today's work in Daily Focus. Capture quickly, plan your week, and move project steps through Ready, In Progress and Finished.

- [Read or download the illustrated PDF guide](downloads/plan-act/Plan_Act_Setup_and_User_Guide.pdf)
- [Download the five Notes templates](downloads/plan-act/Plan_Act_Notes_Templates.zip)
- [Open Plan & Act on the website](https://moealichehade.github.io/moe-apple-lab/#plan-act)

### Install

1. Read PDF pages **2–5** for the planning lists, Smart List filters, Project Tracker board and Notes setup.
2. Open the eight shared Reminders template links on **page 12**. Preview each template before adding it. Recreate and verify the daily Smart Lists using **page 3**; shared list templates do not install the complete system or its live Smart List rules.
3. Extract the Notes ZIP and follow **page 13** to import the five Markdown notes. Pages **14–15** also provide their text to copy.
4. Run the direct test on **page 10** and the launch checklist on **page 16**. Confirm your own lists and filters before relying on the daily view.

### Use each day

Capture tasks in **Quick Capture**. Plan work in **Weekly Focus**, **Weekly Actions** and **Coming Up**. Keep routines in **Repeat Schedule**. Set dates and flag priorities. Open **Daily Focus** in the order **Priorities → Routines → Tasks**. Use **Project Brief** for project context and **Project Tracker** for steps: **Ready → In Progress → Finished**. Moving a step to Finished does not complete it; tick its checkbox too.
